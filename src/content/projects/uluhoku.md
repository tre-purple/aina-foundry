## Overview

Kōkua Kalihi Valley's Ka Lāhui o ka Pō program prepares Native Hawaiian families for childbirth.

Uluhoku takes a cohort's class transcripts and splits them into what each person said, links each quote to the question it answered, and tags it with KKV's Pilinahā framework: Connection to Place, Community, Past, Present & Future, and One's Better Self. From those quotes, AI drafts each person's, family's, and cohort's moʻolelo, organized by Pilinahā, with every sentence citing its source. A practitioner always reviews it before it is shared.

AI runs only on Purple Maiʻa's own LLM servers, and all AI output is labeled as AI-generated.

## Features

- **Transcript processing** — upload class transcripts and the app separates speakers, turns, and the questions they answered
- **Pilinahā tagging** — every quote is tagged to KKV's four Pilinahā areas and can be filtered by them
- **Moʻolelo drafts** — AI writes each person's, family's, and cohort's story from their own words, citing each quote
- **Practitioner review** — nothing reaches families without a practitioner reviewing it
- **Self-hosted AI** — runs only on Purple Maiʻa's LLM servers; output is always labeled
