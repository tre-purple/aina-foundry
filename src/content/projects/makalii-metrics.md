## Overview

Makaliʻi Metrics is a dashboard platform built for community organizations that need to track, visualize, and report on their impact data. The project is in the process of onboarding its first clients while continuing to build out both the technical platform and the public-facing website.

The platform connects to the broader AF ecosystem — Purple Maiʻa already self-hosts LLM endpoints that serve Makaliʻi Metrics, and the project is related to the Kilo LLM/RAG work exploring AI-assisted analysis of mixed quantitative and qualitative data.

## Features

- **Impact dashboard** — visualization platform for community organization data
- **Client onboarding workflow** — customer lifecycle from signup through active use
- **Capabilities page** — recently added to the dev site with updated copywriting
- **Self-hosted AI backend** — served by PMF LLM endpoints

## Phase

Onboarding first clients. Public website being finalized.
