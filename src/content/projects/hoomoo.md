## Overview

Hoʻomoʻo is a prototype matching app built around pilina, the relationships that connect people. Its Pilina Match flow pairs users, who can then view their matches, message each other, and track their connections from a dashboard.

## Features

- **Pilina Match** — matching flow that connects users
- **Your Matches** — a list of each user's matches
- **Messages** — direct messaging between matched users
- **Dashboard** — an overview of each user's activity

## Phase

Early prototype. Currently hosted outside Purple Maiʻa infrastructure.
