## Overview

Kilo LLM/RAG explores using retrieval-augmented generation (RAG) to make dashboard data conversational. Instead of building custom charts for every question, users ask natural language questions and get answers grounded in their actual data — whether that's soil sensor readings, survey responses, or program metrics.

The project sits at the intersection of several AF efforts. It connects to Makaliʻi Metrics (providing the AI analysis layer for dashboard data), the Kilo Dashboard (sensor data from field sites), and the broader KumuBot/Nupepa research system. The initial evaluation work was done through a soil RAG evaluation, testing how well LLMs can retrieve and reason over environmental data.

## Features

- **Natural language data queries** — ask questions of dashboard data in plain language
- **RAG pipeline** — retrieval-augmented generation connecting LLMs to structured data sources
- **Soil data evaluation** — initial testing focused on soil series and environmental data accuracy

## Phase

Early evaluation. Soil RAG pipeline tested; exploring integration with Makaliʻi Metrics and Kilo Dashboard.
